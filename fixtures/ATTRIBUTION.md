# Fixture attribution

The binary `war3map.*` / `war3mapSkin.*` files in this directory are test
fixtures copied from the WC3MapTranslator project's test data
(`test/data/` in https://github.com/ChiefOfGxBxL/WC3MapTranslator),
Copyright (c) 2020 ChiefOfGxBxL, licensed under the MIT License.

They are small synthetic files in the current (Reforged) map formats
(w3i v33, w3e v12, object data v3) and contain no Blizzard-authored map
content. Do NOT add Blizzard maps or other third-party protected maps to
this repository.
