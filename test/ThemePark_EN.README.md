# test/ThemePark_EN.w3x

English translation of **魔兽模拟主题公园 测版13 (WC3 Theme Park,
test build 13)** by **L** — a 4-player competitive Bullfrog-style park
management sim: each player runs a park in one quadrant, building
attractions from statues and gardens up to a Royal Palace and Zeppelin
to draw five guest archetypes with rising satisfaction difficulty and
rising gate fees (Woman 100g → Rich Man 600g). Each archetype is a
SEPARATE popularity pool per player, so the strategic question is
mass-market crowds vs specializing in a harder-to-please, higher-paying
segment while watching what rivals chase. A Boss hero personally picks
up dropped money; Workers build and must SWITCH ON attractions (an
un-switched attraction earns nothing — the map warns you); an
Engineering Department researches three park-expansion tiers that clear
the tree-wall boundary, ending in "Ultimate Park Complete". All 303 wts
entries translated; zero chat commands exist in the script. Gameplay
byte-identical: 26 of 28 members byte-identical (only wts + header
name differ — the script itself is untouched, its Chinese being
comments only); validate-map 40/43 verdict-identical both sides; pjass
diagnostics identical line-for-line; markup parity 0 mismatches.
