# test/CockroachBattle3_EN.w3x

English translation of **Тараканья схватка 3: Metal Gear Insectus,
часть 1** by **Alexstra Studios** (RU) — a 1–2 player co-op story
campaign in a Moscow apartment block, roughly half cinematics.
Quest 1 is an escort/defence; Quest 2 is a **25-minute timed escape**
(15 on Hard) down a collapsing building through 14 trigger-gated rooms
with key-locked doors, caged exterminators to free, and a mini-boss.
Optional quests hide seven dollars and a haunted flat with a Revenant.

**Correction to the brief**: this is NOT a stealth game. "Metal Gear
Insectus" is the BOSS — a building-sized steel cockroach — not a play
style. There is no alert state, no vision cone, no patrol system and no
detection meter anywhere in its 211 triggers.

2,567 wts value blocks translated from 1,799 unique strings (~105,700
Cyrillic chars). Register is crude political meme comedy and is kept at
full strength: profanity uncensored, ethnic slang preserved as slang
(neutralising it erases the joke), ~15 author typos mirrored with
parallel English typos, and two entries reproduced truncated because
the original truncates them mid-character.

Gameplay byte-identical: **459 of 459 members hashed, exactly one
differs** (war3map.wts). The wts scaffold is byte-identical — headers,
comments, braces, separators — with only values changed, so the file's
invalid-UTF-8 comment bytes survive verbatim. validate-map parity
(its 1 FAIL is the pre-existing w3s v1 format with no codec).

Author fields credit "Alexstra Studios, translated by Serendipity";
the trilogy end card and community link are intact. Siblings (parts 1,
2 and chast-2) are not translated.

**Status**: owner-directed translation set (2026-08-09) — same exception
terms as SchoolGhostStory_EN.README.md (download convenience only, not a
bundled map, excluded from all toolkit doctrine).
