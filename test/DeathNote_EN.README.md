# test/DeathNote_EN.w3x

English translation of **Death Note v0.4b** by **Archangel** (BvN team,
vk.com/bvn_team) — a 3–10 player hidden-role deduction map: identical
Detective heroes in a small city, one secretly Kira, one L (7+ players
adds a False Kira). Kira's Write Name kill only works on names he has
learned (ID cards, building records that log YOUR name when queried,
looted corpses — or the Shinigami Contract, all names at double-damage
cost); victims drop a note listing every name THEY knew, seeding the
investigation. Forensics, cameras, votes, arrests, note-renunciation
memory games. Remarkably, the map has ZERO chat commands — every
secret interaction is ability/item/dialog-driven. 84 script literals +
w3i + 90 reachable object/ability/item text sections translated
(reachability computed as a closure over script FourCCs + SLK ability
lists); canonical franchise renderings (Kira, Shinigami, Death Note).
Gameplay byte-identical: exactly 7 members differ, 153 byte-identical
incl. all 108 protected members; the script with string literals
stripped is byte-identical; pjass PASS; validation verdict parity.
Author fields credit "Archangel, translated by Serendipity".
