13-slot co-op build-and-survive: pick a difficulty (Easy→Godlike) and a
mode, chop wood with Robots, then grow a deep tech tree with a SECOND

animal farms, and generator auras. A hostile Genetics Corporation

and kill the Zombie Lord; dead players return as playable zombies.
